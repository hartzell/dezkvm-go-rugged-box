# README

This is a "rugged box" with some bits inside to hold a DezKVM-Go KVM.

It's a riff on @w00h's [JetKVM rugged box].  Like @w00h, I started
with a [paraemetric rugged box] model (I used @Whity's) and added a
cradle in the base and a holder-downer in the lid.

See the upstream project for parts list and assembly instructions.

Following @Whity's lead, I'm distributing this under the
`Attribution-NonCommercial-ShareAlike 4.0 International` license.

The dimensions leave just a bit of wiggle for the DezKVM-Go case;
that's intentional as I like to line the box with a bit of Gaffer's
tape.  If you want to shrink it, you should start with the inner
perimeter in the top-level sketch named `dezKVM perimeter`.

I'm a fusion newbie, FWIW, if I did this again probably do things
differently.  This works though, so lessons learned and on to the next
thing.

I printed this in matte and regular Prusament PETG on a Prusa Core
One+ (the big bits) and a Prusa Mini+ for the latches (because I could
run different colors in parallel) and the seal (because flex filament
is easier to load on the mini).
